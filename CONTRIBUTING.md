# Contributing

- Bug reports / ideas: open an issue. Please **don't paste chat logs, file paths, keys or other personal data** in screenshots.
- New character packs: add `assets/packs/<id>/` with a `manifest.json`; state the artwork license clearly and only submit art you have the right to share.
- Code: keep `npm test` passing; no build step (plain JS in the dsh ModuleLoader format).
